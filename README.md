Aplicación web sencilla desarrollada con Streamlit para anotar fragmentos de texto y clasificarlos como:

- Opinión
- Evidencia
- Indeciso

En caso de seleccionar Opinión o Evidencia, la etiqueta se almacena en la base de dato designada.

En caso de seleccionar Indeciso, se desplega un menú que permite agregar la razón de indecisión y dar un estimado de donde siente el eqtiquetador que cae el texto (0 = opinión, 1 = Evidencia).

Al hacer click en Siguiente se guarda la etiqueta, al hacer click en Actualizar, se cambia el texto.
